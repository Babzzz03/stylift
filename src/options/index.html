StyleLift Settings

StyleLift works fully without a key — extraction is deterministic. A DeepSeek key only unlocks the Polish step, which names and describes the tokens StyleLift already measured. Your key is stored locally in this browser and is sent only to api.deepseek.com from the extension's background worker.

Get a key at platform.deepseek.com.

WordPress

Send captured sections straight into WordPress as Elementor templates or draft pages. Install the StyleLift Importer plugin on your site, then create an application password under Users → Profile → Application Passwords. The password is stored only in this browser and sent only to your site.

Publishing

After an export, the panel's Your export card can publish it to Netlify or Vercel for an https link, or push it to a GitHub repository. Paste a personal access token for each service you use. Tokens are stored only in this browser and sent only to that service.

Netlify

Create one at app.netlify.com → User settings → Applications.

Vercel

Create one at vercel.com/account/tokens.

GitHub

Create one at github.com → Settings → Developer settings: a fine-grained token with Administration and Contents set to read and write (to create repositories and commit to them), or a classic token with the repo scope.
